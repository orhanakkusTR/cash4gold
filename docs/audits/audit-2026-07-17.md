## Method & caveats

- **QUICK mode.** Independently re-ran only lanes 1 (Technical), 2 (Metadata),
  4 (Cannibalization), 5 (Local/NAP). The other 7 dimensions were **not** given a
  fresh specialist pass — their deltas are classified from confirmed RESOLVED
  findings (code-inspection / rendered-output verified this session), and their
  scores are **provisional** until a full-mode re-audit.
- **Read-only.** No code changed during this audit.
- **Rendered-output** checks used plain `curl` (no JavaScript executed) against
  the live production HTML — pre-hydration, exactly as a crawler sees it.
- **Security is OUT of scope** — this audit does not assess TLS, secrets, auth,
  dependency CVEs, or security headers. Absence of security findings is not a
  clean security bill of health.
- **CWV** deltas are risk-from-code (LCP treatment, fetch cadence), not measured
  field data — capture real Lighthouse/CrUX numbers next full run.
